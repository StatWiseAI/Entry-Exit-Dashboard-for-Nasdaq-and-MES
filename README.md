# NQ/ES Trade Decision Dashboard

> **A rules-based signal system for E-Mini Nasdaq-100 (NQ) and S&P 500 (ES) futures.**
> Plain-language entry and exit decisions backed by historical backtesting.
> Built to connect to live broker APIs (Topstep, TradingView) when ready.

## What It Does

| State | What you see | What it means |
|---|---|---|
| **▲ ENTER LONG NOW** | Green pulsing button | All 5 conditions aligned — bullish setup |
| **▼ ENTER SHORT NOW** | Red pulsing button | All 5 conditions aligned — bearish setup |
| **⚡ APPROACHING** | Amber warning | 4/5 conditions met — watch next bar |
| **— WAIT** | Grey / disabled | No edge present — stay flat |

Every signal comes with exact **entry price**, **stop-loss**, **take-profit**, **risk in USD**, and **maximum hold bars** — no interpretation needed.

## Features

- **1m / 5m / 30m / 1H timeframe switcher** — each with independent signal logic
- **Decision card** — one-sentence reason for every signal state
- **Trade plan** — entry, SL, TP, R:R ratio, max hold, all pre-calculated
- **Signal readiness gauge** — shows % progress toward the next signal
- **Backtest table** — every historical trade with entry time, exit time, reason (TP / SL / TIME), pts, and USD P&L
- **Equity curve** — cumulative P&L visualised
- **CSV upload** — drop your own NQ and ES CSV files; full strategy runs in the browser
- **API-ready architecture** — swap the static data for a live feed without changing the dashboard

## CSV Format

Your CSV files must have these columns (FRD / standard OHLCV format):

```
timestamp,open,high,low,close,volume
2026-04-01 09:30,24100.25,24150.00,24080.50,24130.75,1250
2026-04-01 10:00,24130.75,24200.00,24120.00,24185.50,980
```

- **NQ file** — must start with `NQ` in the filename (e.g. `NQ_30min_sample.csv`)
- **ES file** — must start with `ES` in the filename (e.g. `ES_30min_sample.csv`)
- Timestamps must be identical across both files for the strategy to align them

## Strategy Logic

The signal fires when **all 5 conditions** are true simultaneously:

| # | Condition | Long | Short |
|---|---|---|---|
| 1 | **Trend** — EMA20 vs EMA50 | EMA20 > EMA50 | EMA20 < EMA50 |
| 2 | **Pullback** — price vs EMA20 | Price < EMA20 − threshold | Price > EMA20 + threshold |
| 3 | **Momentum** — 3-bar price change | Positive | Negative |
| 4 | **Relative strength** — NQ/ES ratio vs its 20-bar MA | NQ outperforming | ES outperforming |
| 5 | **Correlation** — rolling 20-bar NQ/ES return corr | > 0.70 | > 0.70 |

### Default parameters by timeframe

| Timeframe | Pullback thresh | SL | TP | Max hold |
|---|---|---|---|---|
| 1 min | 0.05% | 0.2% | 0.4% | 10 bars |
| 5 min | 0.10% | 0.3% | 0.6% | 8 bars |
| 30 min | 0.20% | 0.5% | 1.0% | 5 bars |
| 1 hour | 0.30% | 0.7% | 1.4% | 4 bars |

## Python Script — Command Line

```bash
# Install dependencies
pip install pandas numpy

# Process a single timeframe
python nq_es_strategy.py --dir ./data --tf 30min

# Process all timeframes at once
python nq_es_strategy.py --dir ./data --tf all

# Explicit file paths
python nq_es_strategy.py --nq NQ_30min.csv --es ES_30min.csv

# Override strategy parameters
python nq_es_strategy.py --dir ./data --tf 5min \
  --pullback 0.0015 --sl 0.004 --tp 0.008 --hold 6

# Output goes to current directory:
#   nq_es_signal_30min_20260401_143022.json
#   nq_es_signal_30min_20260401_143022.txt
```

## Connecting a Live Data API

The architecture is designed so the dashboard **does not change** when you connect live data.
Only the data source changes. The signal engine and UI are identical.

### Topstep
Topstep provides live NQ/ES data via their **Tradovate** integration.
See `api/topstep_connector.py` for the scaffold.

### TradingView
TradingView Pine Script can push bar data to a webhook URL via alerts.
See `api/tradingview_connector.py` for the receiver scaffold.

Full connection guide: see `DEPLOYMENT_GUIDE.md`
