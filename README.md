# NQ/ES AI Trade Decision System

> **An AI-powered conversational decision-support system for E-Mini NQ and ES futures.**
> Closes the gap between *what happened* and *what should I do now, given who I am as a trader and what the market is doing at this moment.*

---

## The Core Problem This Solves

Existing analytics platforms explain past behaviour with statistical rigour yet remain fundamentally passive. They answer **what happened** — they cannot answer **what should I do now**.

This system addresses that gap by combining three theoretical streams previously unconnected in trading analytics:

| Stream | Theory | Application |
|---|---|---|
| **SCM decision models** | Economic Order Quantity, Newsvendor model, Safety Stock, Bullwhip Effect | Position sizing, SL/TP calibration, daily risk limits, news amplification warnings |
| **Conversational AI with persistent memory** | Stateful LLM agent with trader profile | Personalised decisions that remember your biases, session P&L, emotional state, and trade history |
| **Real-time external intelligence** | Market microstructure + macro calendar + news | VIX regime, macro event proximity, breaking news risk, order flow context |

## What the System Outputs

Every bar produces a single, unambiguous decision:

| State | Button | Meaning |
|---|---|---|
| **▲ ENTER LONG NOW** | Green, pulsing | All 5 conditions aligned + agent confirmed + SCM check passed |
| **▼ ENTER SHORT NOW** | Red, pulsing | As above, short direction |
| **⚡ APPROACHING** | Amber | 4/5 conditions met — watch next bar |
| **— WAIT** | Grey, disabled | No edge, or safety check failed |

Each decision includes:
- **Exact entry, SL, TP** in price and USD
- **SCM-sized contract count** (EOQ model)
- **Newsvendor-calibrated SL/TP** (adjusted to your historical win rate)
- **Plain-language reason** (one sentence — no indicator lists)
- **Personalised agent note** (references your profile and recent session)
- **Bullwhip warnings** (macro events, VIX spikes, breaking news)

## SCM Theoretical Framework

### EOQ → Position Sizing
Classical EOQ balances ordering cost vs holding cost.
Here: risk cost (drawdown per unit) vs opportunity cost (being flat).
Position size scales with signal confidence and inversely with VIX-derived volatility.

```
adjusted_risk = base_risk × vol_adj × confidence_adj × news_adj × macro_adj
contracts     = adjusted_risk / (sl_pct × entry × $20)
```

### Newsvendor Model → SL/TP Optimisation
The newsvendor chooses stock to maximise profit under uncertain demand.
Here: choose SL/TP to maximise expected P&L given the signal's historical win rate.

```
critical_ratio = TP / (TP + SL)           # fair win rate for this R:R
if win_rate > critical_ratio → widen TP   # we win more than needed → take more
if win_rate < critical_ratio → tighten SL # we win less → reduce per-loss cost
```

### Safety Stock → Daily Risk Buffer
Minimum account buffer before entering a new trade:
- Hard stop: daily loss limit reached
- Hard stop: 3 consecutive losses today
- Soft warning: trades-today limit reached
- Soft warning: emotional state flagged

### Bullwhip Effect → News Amplification Warning
Breaking news causes overreaction (amplified upstream swing for a small demand change).
Agent flags this when: VIX spikes, macro event is <30min away, or news risk = high.
Recommended action: wait for the reaction to settle before entering.

## Quickstart

### 1. Static dashboard (no server, free)
Rename `index.html`, upload to GitHub, enable Pages. Done in 10 minutes.
See `DEPLOYMENT_GUIDE.md` Part 1.

### 2. Full AI app (Streamlit Cloud, free)
```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-..."
streamlit run streamlit_app.py
```
Upload your CSV files → agent analyses → decision card appears.

### 3. CLI strategy processor
```bash
python nq_es_strategy.py --dir ./data --tf 30min
python nq_es_strategy.py --dir ./data --tf all
python nq_es_strategy.py --nq NQ_5min.csv --es ES_5min.csv --sl 0.004 --tp 0.008
```
